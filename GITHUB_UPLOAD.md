# GitHub-Upload

## Vor dem ersten Upload

Die Repository-Links sind bereits auf `Sachverstand1965/SunnySense` eingestellt.
Optional kann in der MIT-Lizenz der Copyright-Inhaber angepasst werden.

Repository-Name: `SunnySense`.

## Upload über die GitHub-Webseite

1. Auf GitHub ein öffentliches Repository `ha-is-sunny` ohne automatisch
   erzeugte README oder Lizenz erstellen.
2. **Add file → Upload files** wählen.
3. Den gesamten Inhalt dieses Pakets einschließlich `.github`,
   `custom_components`, `tools` und der Dateien im Stammverzeichnis hochladen.
4. Als Commit-Nachricht `Initial release 0.1.0` verwenden.
5. Unter **Releases → Draft a new release** den Tag `0.1.0` erstellen und
   veröffentlichen. Der Release-Workflow hängt das Installations-ZIP an.

## Installation als benutzerdefiniertes HACS-Repository

In HACS über **Custom repositories** die GitHub-URL eintragen und als Kategorie
**Integration** wählen. Für eine Aufnahme in den HACS-Standardkatalog gelten
zusätzliche HACS-Prüf- und Veröffentlichungsanforderungen.
