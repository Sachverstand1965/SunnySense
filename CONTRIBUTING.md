# Mitwirken

Fehlerberichte und Pull Requests sind willkommen.

1. Repository forken und einen Branch vom aktuellen `main` erstellen.
2. Änderungen klein und nachvollziehbar halten.
3. `python -m compileall custom_components tools tests` und `pytest` ausführen.
4. Bei Änderungen am Modell passende Tests und einen Changelog-Eintrag ergänzen.
5. Keine realen Home-Assistant-Exporte oder Standortdaten veröffentlichen.

Für reproduzierbare Modellfehler bitte anonymisierte Sensorwerte, Home-Assistant-
Version, Integrationsversion und die Diagnoseattribute angeben.
