# Sicherheitsrichtlinie

Bitte Sicherheitsprobleme nicht als öffentliches Issue melden. Nutze stattdessen
GitHubs Funktion **Security → Report a vulnerability**. Unterstützt wird jeweils
die neueste veröffentlichte Version.

Die Integration kommuniziert nicht mit externen Diensten und speichert das
Lernmodell ausschließlich in Home Assistants lokalem `.storage`-Verzeichnis.
